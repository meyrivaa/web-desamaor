BATAS PENGUJIAN DI LINGKUNGAN PEMBUATAN PAKET
Dependency Composer/vendor tidak disertakan karena lingkungan pembuatan paket
ini tidak dapat mengakses Packagist. Karena itu server Laravel dan browser
belum dapat dijalankan langsung di lingkungan tersebut.

Pengujian runtime dilakukan setelah ekstrak dengan:
  composer install
  php artisan optimize:clear
  php artisan test
  php artisan serve

Komputer pengguna yang sebelumnya menampilkan PHP 8.4.23 dan Composer 2.9.5
sudah memenuhi persyaratan dasar proyek ini.
